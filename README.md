# MultiTool 多功能工具 — Downloads 下載

All-in-one Windows toolbox: automation scripts with live monitor mode, AI assistant, screen recorder & instant replay, converter, video downloader, game servers, performance monitor and more.

一站式 Windows 工具箱：自動化腳本（監視模式）、AI 助手、錄影及精彩重播、轉檔、影片下載、遊戲伺服器、效能監看等。

Developed by / 開發者：**白兔糖v3v**

## Download 下載

👉 **[Latest release 最新版本](https://github.com/jeffpny1123/MultiTool-Releases/releases/latest)**

1. Download `MultiTool-vX.X.zip` and extract it.
   下載 `MultiTool-vX.X.zip` 並解壓。
2. Run `MultiTool.exe` — no installation or .NET needed.
   直接執行 `MultiTool.exe`，無須安裝，亦無須 .NET。
3. MultiTool updates itself automatically when a new version is released here.
   有新版本時，MultiTool 會自動更新。

Keep `MultiTool.exe` and the `data` folder together — your scripts and settings are stored in `data`.
`MultiTool.exe` 須與 `data` 資料夾放在一起，你的腳本及設定都儲存在 `data` 內。

> If a game runs as Administrator, run MultiTool as Administrator too, or Windows will block clicks and key presses.
> 若遊戲以系統管理員身分執行，MultiTool 亦須以系統管理員身分執行，否則 Windows 會阻擋點擊及按鍵。
